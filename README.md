# REPOSITORY-OF-ASSETS

Catálogo central dos **personagens** já produzidos nos jogos da casa.

**Regra:** antes de gerar ou modelar um personagem novo, o ilustrador procura aqui. Se já existir (ou algo próximo), **reaproveite** a arte-fonte do projeto indicado.

| Arquivo | Conteúdo |
|---|---|
| [characters-games-2d.md](characters-games-2d.md) | Personagens 2D: Banana King (todas as poses de todos os jogos), inimigos, chefes, NPCs, dançarinas K-pop, as espiãs do K-Pop Secret Agents (outfits, informantes, alvos de missão, shows), mascotes |
| [characters-games-3d.md](characters-games-3d.md) | Personagens 3D (com coluna de **rig**): gato e rato do Mouse-Hunt, Kako e operadores do kako-steel |

Cada linha traz: nome da imagem/personagem · descrição · se tem animação · em qual jogo/pasta está · tipo de arte (e rig, no 3D).
